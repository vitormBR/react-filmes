FilmeFlix

alunos: Vitor Miguel , David José , Kayk Gomes

Aplicação para visualizar e gerenciar filmes cadastrados no sistema.

O projeto possui backend em Express, banco SQLite e autenticação de usuários.
Foi criada uma API para fornecer os filmes cadastrados.
A interface React consulta a API e exibe os filmes usando useState, useEffect e fetch.
